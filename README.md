# Semiconductor Supply Chain Map

Interactive map of the global semiconductor supply chain, with disruption scenarios.

- `data/` – seed, extracted and built graph data (versioned)
- `schema/` – JSON Schemas for nodes, edges, evidence and extraction output
- `pipeline/` – Python package `scg`: ingest, extraction, graph build, analysis
- `web/` – static front end (Vite + TypeScript, Cytoscape.js, D3)
- `docs/` – methodology and data dictionary
